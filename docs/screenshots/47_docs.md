## Visual Style Notes

- **Dark theme:** Background is dark charcoal (#1a1a2e or similar), text is white/light gray
- **Link color:** White text for links (no blue underlines — clean minimal style)
- **Accent color:** Red for active sidebar item ("Docs Home") and card icons
- **Cards:** Dark background with subtle lighter border, rounded corners
- **Typography:** Clean sans-serif font, good hierarchy between headers, subtitles, and body text
- **Sidebar sections:** Collapsible with right-pointing chevrons (▶)
- **Content density:** Very high — the right column contains 60+ documentation links
- **Layout:** Single-page documentation index with two audience-segmented columns
