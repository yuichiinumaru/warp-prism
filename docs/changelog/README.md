# Warp Prism Local Changelog

changelog engine is introduced.

Rules:

- Add one dated Markdown file per meaningful child-local change.
- Do not edit parent Ganthritor `CHANGELOG.md` manually.
- Use the parent Ganthritor changelog engine when parent harness assets change.
- Keep entries factual and link tasks, reports, and validation evidence.
