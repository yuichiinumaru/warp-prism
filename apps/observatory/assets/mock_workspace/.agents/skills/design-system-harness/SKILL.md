# design-system-harness

## Purpose

Constructs and maintains the Atomic Design System. Manages design tokens, creates atomic components (atoms, molecules, organisms, templates, pages), and maintains the Design System Gallery.

## Design System Layers

1. **Tokens**: Colors, typography, spacing, radii, shadows, motion, semantics
2. **Atoms**: Text, Icon, Badge, Chip, Divider, StatusDot, GlowBorder, GlassPanel
3. **Molecules**: SearchBar, FilterChipGroup, AssetCard, MetricTile, ProvenancePill
4. **Organisms**: Shell, Sidebar, Topbar, GraphCanvas, LaneBoard, Timeline
5. **Templates**: Map, Operate, History, Governance
6. **Pages**: Design System Gallery

## When To Use

- Building new UI components
- Defining or modifying design tokens
- Creating template layouts
- Updating the Design System Gallery

## Sub-Skills

- `token-management`: Token definition and modification
- `atomic-components`: Atom and molecule creation
- `pattern-library`: Organism and template patterns
- `gallery-maintenance`: Gallery page updates and demos
