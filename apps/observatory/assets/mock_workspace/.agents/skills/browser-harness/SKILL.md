# browser-harness

## Purpose

Provides browser automation capabilities for research, testing, and validation. Can navigate pages, interact with elements, capture screenshots, and extract data from web sources.

## When To Use

- Automating web research tasks
- Capturing screenshots for evidence
- Testing web-based features
- Extracting data from external documentation

## Capabilities

- **Navigation**: URL loading, page waiting, redirect following
- **Interaction**: Click, type, select, scroll, hover
- **Capture**: Screenshots, page content, network requests
- **Extraction**: DOM queries, text extraction, link harvesting

## Sub-Skills

- `page-navigation`: URL loading and page state management
- `element-interaction`: DOM element interaction patterns
- `screenshot-capture`: Visual evidence capture
- `data-extraction`: Structured data extraction from pages
