# external-intelligence

## Purpose

Gathers and synthesizes information from external sources. Manages research workflows, source credibility assessment, and knowledge distillation for workspace consumption.

## When To Use

- Research tasks assigned from the planning lane
- API documentation lookup for implementation
- Competitive analysis for feature decisions
- External validation of technical approaches

## Source Types

- **Documentation**: Official API and library docs
- **Repositories**: Open source code and patterns
- **Articles**: Technical articles and blog posts
- **Standards**: Industry standards and specifications

## Sub-Skills

- `source-management`: Source cataloging and credibility tracking
- `research-methodology`: Structured research execution
- `knowledge-synthesis`: Finding distillation and reporting
- `validation-check`: Cross-reference validation against workspace needs
