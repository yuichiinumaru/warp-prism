## Status Note

The scripts in `scripts/` are **experimental** and have not yet been canonized as part of the flutter workflow. They were copied verbatim from their source repositories and should be evaluated during real Flutter tasks before being referenced in sub-skills or workflows. Canonization happens when:

1. A real Flutter task exercises the script and confirms it works correctly in the Ganthritor context
2. The script's output is validated against expected behavior
3. A sub-skill or workflow references the script with clear invocation instructions
4. The script is documented in `scripts-status.md` with status promoted from `experimental` to `canonized`

Until then, treat these as reference implementations — useful for understanding patterns but not yet trusted for automated execution.
